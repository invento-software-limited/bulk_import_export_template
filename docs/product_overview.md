# Bulk Import Export Template

**Bulk Import Export Template** is a Frappe app that supercharges the built-in Data Import tool by letting you create, save, and reuse custom field selection templates. Stop manually picking fields every time — pick once, save as a favourite, and apply instantly.

---

## Target Audience

- **ERPNext Administrators** who regularly import or export data across multiple DocTypes
- **Implementation Consultants** setting up data migration for new clients
- **Data Entry Teams** handling repetitive bulk operations in ERPNext
- **Developers** building integrations that need consistent field mappings

---

## Key Features

### 🎯 Customizable Field Selection Templates
Precision-select fields for **any DocType**, including full support for nested **child table fields**. The interactive field picker lets you drill into child tables and choose exactly the fields you need.

### 💾 Template Persistence (Favourites)
Save your carefully configured field selections as **Favourite** templates with a single click. Each template stores:
- The target DocType
- Selected fields and their order
- Child table field selections (nested any depth)
- A descriptive name for easy identification

### 🔌 Seamless Data Import Integration
Plugs directly into Frappe's native **Data Import** tool. When preparing an import or export, click the **Select Favourite** button and pick your saved template — fields are applied instantly.

### ⚡ Boosted Efficiency
- Eliminate repetitive field mapping for recurring imports
- Reduce human error from manual field selection
- Standardise field sets across your team
- Drastically cut data preparation time

### 🔄 Export & Import Parity
Templates work for **both import and export** operations. Configure once, use for pulling data out or pushing data in.
